# Shree Jay Jalaram Khaman House — Website Redesign

A responsive, English-only Gujarati snacks website built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build step or server is required. For local development you can also run `python -m http.server 8000` from this folder and open http://localhost:8000.

## Features
- Animated brand intro and responsive navigation
- Brand story and actual uploaded food photography
- Searchable/filterable menu and interactive cart
- Checkout fields for customer, phone, pickup/delivery, outlet and notes
- WhatsApp order message sent to +91 98987 94111
- Printable invoice (choose “Save as PDF” in the browser print dialog)
- Two branch cards with Google Maps directions links
- Instagram link to @jay_jalaramkhaman
- Lightweight scroll reveals and hover animations
